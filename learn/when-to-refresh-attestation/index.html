When to refresh the attestation

Last reviewed October 26, 2026

The affirmation speaks as of the date in the file. Every word of it - true, accurate, complete - is anchored to the file's own date, so each update of the standard charge information is also a new attestation.

Hospitals must update their standard charge information at least annually. That makes the attestation a recurring act, not a one-time setup. A file updated this month carries a fresh affirmation whether or not anyone thought about the words.

Two refresh triggers deserve a calendar entry. The first is the regular update cycle: the review that supports the affirmation should be part of every repost, not an annual afterthought. The second is a change of attester: when the named official changes roles or leaves, the name in the file is stale the day the next update posts - and arguably awkward sooner.

Build the refresh into the update workflow itself, so no one can repost the file without re-facing the statement.
