Hospital price transparency

The top file-quality failure modes

Last reviewed October 26, 2026

The 2026 gap types, kept from the live page: percentage or algorithm charges with no dollar allowed amounts; a missing count of allowed amounts; allowed amounts built from the wrong period or data source; no Type 2 NPI; an old affirmation statement or no named official; blank or zero cells with no explanation. Each traces to a named CY 2026 data element.

Around those sit the failures that predate 2026 and still fill enforcement letters. The file that cannot be found: no footer link, no root .txt, a URL that 404s after a site redesign. The file that cannot be fetched: a login wall, a registration form, a CAPTCHA or a bot rule between the public and the data. The file that cannot be parsed: a format outside the CMS templates, or schema breaks a human never sees in a spreadsheet.

The stale file: past its annual update, affirming charges that no longer match any contract. And the quietly incomplete file: five standard charges exist on paper, but one is systematically empty because the data source was never mapped.

What ties them together is that none requires inside knowledge to find. CMS monitoring works from outside: fetch the file, check the access path, parse it, sample it. Every failure mode in this cluster is visible to a stranger with a command line, which is exactly why each has its own page here.
