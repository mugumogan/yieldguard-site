What the CMS attestation is

Last reviewed October 26, 2026

The earlier affirmation requirement in 45 CFR 180.50(a)(3)(i)-(ii) began January 1, 2024 and ran through December 31, 2025. CMS's technical implementation table separately lists July 1, 2024 for enforcement of the standardized-template affirmation field. Beginning January 1, 2026, the modified attestation adds dollar-amount and derivability language and requires the name of the CEO, president or designated senior official; CMS delayed enforcement of those new MRF requirements until April 1, 2026.

The attestation belongs inside the MRF, not beside it. The CMS JSON layout uses an attestation object containing the prescribed statement, confirmation and attester name; CSV has its own general-data layout. Use the applicable current dictionary rather than assuming JSON field placement applies to every format.

This shapes what posting a file means. Each update republishes the data and renews the statement about that data in the same act. A team that treats the affirmation as a formality is confirming something it has not read.
