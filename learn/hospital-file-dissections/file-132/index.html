Hospital file #132: 19,942 zero-count entries need absence explanations

Published November 13, 2026 · Source audit: Tuesday, October 6, 2026, 4:48 PM PDT (direct verification update cutoff)

Stored audit of one hospital price file found 19,942 count-zero entries without a no-remittance explanation across 167,091 applicable entries. Historical, de-identified review; not a fresh endpoint check.

What the stored audit found

JSON files change the shape of the audit, not the underlying question. Each service record can carry many payer entries, so a small service count can still hide a large conditional-entry count. This file gives the series a JSON-native example.

The October 6 audit found 19,942 coded conditional count-zero entries with blank stats, blank generic notes and payer notes that describe methodology. The denominator is 167,091 applicable conditional entries.

The JSON structure is why the denominator matters. A reader who sees 7,851 service records might assume the review population is small. The audit counted payer-level conditional entries and reached 167,091 applicable entries. These are different units and must not be interchanged.

The gap bucket is specific: methodology-only payer notes and blank generic notes. A payment formula does not say that no remittance existed. The audit did not mix those rows with the 143,286 NoClaimsDataAvailable holds, because those rows at least attempt an absence-related explanation.

The positive entries are also useful. There are 3,863 valid positives with all stats, including 2,893 suppressed counts. That shows the file can encode the positive path correctly. The confirmed problem sits only in the count-zero note path.

What a correction team should do

  • Extract the 19,942 affected payer entries and map them back to their parent service records before editing.
  • Choose whether the absence explanation belongs in generic notes or payer-specific notes, then apply one consistent pattern.
  • Keep NoClaimsDataAvailable rows in a separate adequacy review.
  • After republication, rerun both the service-record count and payer-entry census so the denominator does not shift silently.
