What the stored audit found

The stored audit found 6,233 unique affected entries across more than one zero-count finding class. No share is calculated because the applicable denominator is unavailable.

The classes can overlap or be disjoint. Use the recorded within-file union and intersection rule rather than assuming that adding class counts is valid. The unit reported here is the unique affected entry.

Track each affected entry once, with a separate flag for each condition actually found. Where both conditions occur, clearing a statistic does not settle the explanation issue, and adding a note does not settle an inappropriate statistic.
