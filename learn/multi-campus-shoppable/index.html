Hospital price transparency

Shoppable services for multi-campus systems

Last reviewed October 26, 2026

A health system's shared website must not hide which hospital location a published shoppable charge belongs to. The list requirements at 45 CFR 180.60(b)(7) and (d)(2) require the location to be identified, including whether the charges apply there in the inpatient setting, outpatient department setting, or both.

A central landing page can help visitors find the right disclosure, but a system name alone does not explain which campus offers a service or which location's charges apply. Recommended practice is to make the location choice clear before presenting the list, then retain the location and setting beside the service result. This is a design recommendation for implementing the required location identification, not a prescribed screen layout.

The estimator alternative has its own criteria at 45 CFR 180.60(a)(2). CMS's ten-step guide encourages clear location and inpatient/outpatient information for multi-location estimators. Keep that agency recommendation distinct from the specific location fields required for the published-list route.

For internal review, map hospital locations, the services each provides, the public route used, and the team responsible for updating it. Test that users can reach the intended campus's result rather than being sent to a different location without an explanation. This inventory is recommended governance work; it does not replace either the shoppable disclosure or the separately required MRF.
