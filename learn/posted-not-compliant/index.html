Hospital price transparency

Posted is not compliant

Last reviewed October 26, 2026

The most expensive misunderstanding in hospital price transparency is treating the posting as the requirement. The requirement is a complete, accurate, accessible file plus a consumer-friendly shoppable display, kept current. A hospital can have a link on its website and be out of compliance on every dimension that matters.

CMS's own penalty structure encodes the distinction. A hospital that waives its hearing rights within 30 calendar days can receive a 35 percent reduction of the civil monetary penalty. That reduction is not available for the core failures - no public machine-readable file at all, or no consumer-friendly display of shoppable services - nor when the same instance of noncompliance draws a repeat penalty. Everything else sits on a spectrum that CMS works through warning notices and corrective action plans.

The CY 2026 attestation sharpens the point. A posted file affirms, in the file itself, that the hospital has included all applicable standard charge information and that it is true, accurate and complete as of the file's date. Posting a file known to be incomplete is no longer a quiet gap; it is a signed statement that does not hold.

The compliance question is therefore not 'is it up' but 'does it hold': could the named official defend every element of the affirmation if CMS asked for the certification behind it?
