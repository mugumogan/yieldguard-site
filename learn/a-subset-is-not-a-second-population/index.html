A subset is not a second population

November 17, 2026 · Stored October 2026 audit

Stored file #143 has two finding classes: 624 entries with an inverse-encoding pattern and 1,159 entries with a missing-explanation pattern. The recorded audit says that all 624 are included in the larger group. The unique affected population is therefore 1,159, not 1,783.

This is not a reason to discard the smaller finding. Keep both condition flags on each affected entry, but count each entry once when reporting the unique population. The flags answer what needs work; the union answers how many entries are affected.

The stored applicable population is 8,974 entries. The published union share, 12.915%, describes that October source-bound population only. It does not describe other files, current conditions, payment error or financial loss.
