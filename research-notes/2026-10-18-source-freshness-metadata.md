# Research note: source freshness metadata

Proposed audit fields: retrieval timestamp; embedded update date; source snapshot checksum; parse status; column width check; selection rule. Retrieval date and embedded update date remain separate. A matching checksum can support a same-bytes comparison, not a claim about current hospital operations. This note describes evidence handling and publishes no source identifiers.
